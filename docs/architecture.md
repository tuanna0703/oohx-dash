This is SSP Platofrm (Supply side Provider) for OOH/DOOH in Viet Nam. 
We build it to connect Media Owners in Viet Nam(phase 1) (Media Owner mean vendor or provider)
We use Laravel 12 
The architecture of SSP is:
1. Multi-tenant and each tenant play a role as media owner
2.Tenant has some roles:
- Owner
- Manager
- Sale Manager
- Scheduler
- Read Only
- Report Only
